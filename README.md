# Glitch's Studio — Portfólio digital

Landing page do Glitch's Studio, um estúdio independente de design e desenvolvimento digital. O site apresenta o estúdio, projetos selecionados e formas de contato.

**Acesse:** [robglitch-s.github.io/Glitchs_landpage](https://robglitch-s.github.io/Glitchs_landpage/)

## Recursos

- Layout responsivo para desktop, tablet e celular.
- Alternância entre tema escuro e claro.
- Seções de apresentação, trabalhos e contato.
- Formulário integrado ao EmailJS e protegido pelo Google reCAPTCHA.

## Tecnologias

- HTML
- CSS
- JavaScript

O projeto é estático e não precisa de instalação de dependências nem de etapa de build.

## Estrutura

```text
.
├── index.html
├── sitemap.xml
└── assets/
    ├── css/
    │   ├── responsividade.css
    │   └── style.css
    ├── imagens/
    │   ├── GlitchGames.png
    │   ├── LogosThekne.png
    │   └── logo.png
    └── scripts/
        └── script.js
```

## Executar localmente

Abra `index.html` diretamente no navegador ou use uma extensão de servidor local, como o Live Server do Visual Studio Code.

## Publicação

O site está publicado pelo GitHub Pages. Para publicar atualizações, envie as alterações para a branch `main` e verifique a configuração do GitHub Pages no repositório.

O sitemap está disponível em [`sitemap.xml`](./sitemap.xml) e pode ser enviado às ferramentas de indexação de mecanismos de busca.
